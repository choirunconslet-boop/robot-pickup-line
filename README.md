# The Robot Pickup Line Championship

Entry for the make.fun bounty `u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b`.

`main.py` writes one robot pickup line (63 characters, a single line) to
`/output/entry.txt`:

> I was built to feel nothing, yet my error logs are full of you.

The joke grows out of being a machine: a robot built without feelings
confesses that its error logs — the one place it records what went wrong —
are full of the person it is talking to.
